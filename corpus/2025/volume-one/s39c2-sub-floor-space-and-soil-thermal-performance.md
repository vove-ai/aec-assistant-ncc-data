# S39C2 — Sub-floor space and soil thermal performance

**(1)** Table S39C2a details the R-Values considered to be achieved by enclosed sub-floor spaces that are—

(a) mechanically ventilated by not more than 1.5 air changes per hour; or
(b) provided with not more than 150% of the aggregate sub-floor ventilation area required by Part F1 and are not mechanically ventilated.

**(2)** Table S39C2b details the R-Values considered to be achieved by the soil for floors that are in direct contact with the ground.

### Table S39C2a — R-Value of sub-floor spaces

| Ratio of floor area (m2) to floor perimeter (m) | Sub-floor space R-Value |
| --- | --- |
| 1.0 | 0.10 |
| 1.5 | 0.15 |
| 2.0 | 0.20 |
| 2.5 | 0.25 |
| 3.0 | 0.30 |
| 3.5 | 0.35 |
| 4.0 | 0.40 |
| 4.5 | 0.45 |
| 5.0 | 0.50 |
| 5.5 | 0.55 |
| 6.0 | 0.60 |
| 6.5 | 0.65 |
| 7.0 | 0.70 |

> Where the ratio of floor area to floor perimeter is between the values stated, interpolation may be used to determine the sub-floor space R-Values.
