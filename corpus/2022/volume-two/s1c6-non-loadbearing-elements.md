# S1C6 — Non-loadbearing elements

**(1)** If a non-loadbearing element is able to be used for a purpose where the Deemed-to-Satisfy Provisions prescribe an FRL for structural adequacy, integrity and insulation, that non-loadbearing element need not comply with the structural adequacy criteria.
