# G7D2 — Livable housing design

**(1)** Each sole-occupancy unit in a Class 2 building must comply with the ABCB Standard for Livable Housing Design, except for Part 1.

> **Info**
>
> Part 1 of the [ABCB Standard for Livable Housing Design](https://abcb.gov.au/sites/default/files/resources/2023/livable-housing-design-20230406.pdf) requires a step-free access path from a parking space or property boundary, to the dwelling entry door. For Class 2 buildings, this requirement is already addressed by Part D4 and the Disability (Access to Premises—Buildings) Standards 2010. Therefore, it is not necessary to apply Part 1 of the ABCB Standard for Livable Housing Design to a Class 2 building.
