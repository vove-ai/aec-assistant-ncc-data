# S23C6 — Signal isolation interface units

**(1)** Signal isolation interface units must isolate any low voltage connected to the smoke alarms from the local fire indicator panel.

**(2)** Signal isolation interface units must be certified by an Accredited Testing Laboratory as compatible with the specific types of smoke alarms used in the system.

**(3)** Signal isolation interface units must be accepted by the electricity supply authority.

**(4)** Units must be marked in a clearly visible location, with letters greater than or equal to 35 mm containing the following information:

SMOKE ALARM SIGNAL ISOLATION UNIT WARNING – 240 V

Isolate power supply before removing cover
