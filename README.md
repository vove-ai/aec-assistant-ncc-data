# aec-assistant-ncc-data

National Construction Code (NCC) 2022 and 2025, normalized to one markdown file per unit — clause,
clause variation, glossary entry or page — for exact text search (grep) with clause-level citations. Consumed by AEC Assistant's agents as a
mounted repository. Derived from the verbatim ABCB XML datasets redistributed by
[alvar-ncc-data](https://github.com/vove-ai/alvar-ncc-data) (release `ncc-2026-07`, SHA-256
verified — see `tools/checksums.json`).

Both NCC editions are concurrently in force in Australia; the applicable edition follows a
project's permit application lodgement date.

## Editions and amendment state

| edition | files | dataset | amendment state |
|---|---|---|---|
| NCC 2025 | 3,101 | ABCB XML dataset v1.2 | as published |
| NCC 2022 | 2,997 | ABCB XML packages, `ncc-2026-07` | **as first published, no amendment** |

The NCC 2022 packages are dual-state editorial files: the NCC 2022 text carries the NCC 2025
draft edits on top as tracked changes, so the corpus is built from the base view (insertions
rejected, deletions restored). The base text predates both NCC 2022 amendments — Amendment 1
was adopted 1 May 2025 and Amendment 2 on 29 July 2025, and neither appears in the packages'
own adoption-history table. Measured, with the evidence, in `docs/content-model-2022.md` §8.

## Layout

Everything under `corpus/` is generated by the toolchain in `tools/` and searched by agents —
see `AGENTS.md` for the search contract and `corpus/INDEX.md` for the map. **6,098 files**: NCC 2025
is 3,101 (clause 2,312 · glossary 555 · page 234) across Volumes One to Three, the Housing
Provisions and Livable Housing Design; NCC 2022 is 2,997 (clause 2,225 · glossary 513 · page 259)
across the same four documents, which is every clause its source packages contain — the eight they
do not are named with their evidence in `corpus/2022/INDEX.md`. Regenerate with
`npm ci && npm run fetch && npm run build`; CI regenerates both editions on every push and fails if
the committed corpus and the toolchain disagree by one byte.

**Changes: yes — this is a derivative of both editions.** Relative to the ABCB XML publications:
content is split to one file per clause/definition/page; markup is normalized to markdown; glossary
cross-references are inlined as plain prose; figure references are rewritten to CDN URLs;
citation metadata is added as YAML frontmatter. The glossary, which each volume republishes in
full, is emitted once per edition with its source documents named in `sources:`; where those
documents publish a definition differently, every wording is kept, each under a heading naming
the volumes it came from. This repository is not affiliated with, and
its contents are not endorsed by, the ABCB. The NCC as published at
[ncc.abcb.gov.au](https://ncc.abcb.gov.au/) remains the authoritative source — verify anything
safety-critical there.
